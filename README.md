
# ANSU CREATE

### Ideas into Products.

ANSU CREATE is a mobile-first digital products storefront.

## Features

- Minimal, premium design
- Digital product catalogue
- Product search and categories
- Shopping cart interface
- Admin dashboard demo
- Product add, edit and delete interface
- Firebase integration planned

## Technology

- React
- TypeScript
- Vite
- Firebase
- CSS

## Setup

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Important

The current admin dashboard is a frontend demo.
Firebase authentication, database persistence, secure payments and
protected digital downloads must be configured before production use.
